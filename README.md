# おきもちぼ～ど (仮)

## 概要
**おきもちぼ～ど** は、
- 「今、邪魔されたくない」や「話しかけて欲しい」などの **ステータス** を、
- PC・スマホのカメラで **ジェスチャー**（👍、👎 など）や **顔表情** を認識して取得し、
- その結果を **Web アプリ** 上にリアルタイムで表示するツールです。

### コンセプト
- 周囲の人に自分の「今の状態」を視覚的に伝える。
- 余計なフルスクリーン表示は避け、**レスポンシブ** デザインで PC とモバイル双方に自然に溶け込む UI を提供。
- UI は **かわいいひらがな系** デザインで、利用シーンを楽しく演出。

## 主な機能 (MVP)
1. **ジェスチャー認識**
   - カメラ映像から 👍 / 👎 /  などのシンプルなジェスチャーを検出。
2. **ステータス表示**
   - `多忙`, `暇`, `作業中` といったステータスを Web アプリ上にリアルタイムで表示。
3. **レスポンシブ UI**
   - PC とスマートフォンの画面幅に合わせて美しく表示。
4. **将来的な拡張**（任意）
   - 顔表情認識による自動ステータス判定。
   - カスタムステータスやテーマカラーの変更。

## 技術構成
- **フロントエンド**: React, MediaPipe (HandPose)
- **バックエンド**: Go (WebSocket)
- **データベース**: Supabase
- **デプロイ**: Cloud Run / Render / Vercel

## セットアップ手順
1. **リポジトリをクローン**（既にクローン済み）
   ```bash
   git clone https://github.com/NxTEND-THE-HACK/2026-Team-02
   cd 2026-Team-02
   ```
2. **依存パッケージをインストール**
   ```bash
   npm install
   ```
3. **開発サーバを起動**（ローカルで確認）
   ```bash
   npm run dev
   ```
   ブラウザで `http://localhost:5173` にアクセスすると、カメラ許可を求められた後に UI が表示されます。

## 使い方
1. ページが表示されたら **カメラ許可** を許可。
2. 手のジェスチャーや顔の表情をカメラに映す。
3. 認識されたステータスが画面右上に **可愛い吹き出し** で表示されます。
4. 必要に応じて UI の `設定` ボタンから **ステータスのテキスト** をカスタマイズ可能（将来的な実装予定）。
